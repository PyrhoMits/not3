# 🛒 Not3 Marketplace

A **free, community-maintained** catalog of packs for [Not3](https://github.com/PyrhoMits/not3), including page templates, color palettes, and stickers. All content must use a free-content license.

> This directory mirrors the structure of the separate `inklus-marketplace` repository. The app currently reads the catalog from `https://cdn.jsdelivr.net/gh/Pedroj-64/inklus-marketplace@main/` (`MarketplaceService.defaultBaseUrl`) and falls back to its bundled catalog when the remote catalog is unavailable.

## How it works

```
packs/<id>/manifest.json   ← authored pack metadata
packs/<id>/*.png           ← images (stickers, template backgrounds, and previews)
catalog.json               ← generated by CI (DO NOT edit manually): manifests, SHA-256 hashes, and sizes
```

1. Every pull request is validated with `dart run bin/build_catalog.dart --check`.
2. When a pull request is merged into `main`, CI regenerates and publishes `catalog.json`.
3. jsDelivr serves the files through its free CDN. The app downloads the catalog and verifies the **SHA-256 hash and size** of every file before saving an installed pack. Downloaded content is never executed.

## Publish a pack

1. Fork the marketplace repository and create `packs/<your-id>/manifest.json`. IDs may contain lowercase letters, numbers, and hyphens.
2. Add your images under `packs/<your-id>/` (PNG, JPG, or WebP; maximum 5 MB per file and 20 MB total).
3. Run `dart pub get && dart run bin/build_catalog.dart --check`.
4. Open a pull request. A maintainer will review it; see `CODEOWNERS`.

### Pack types

**Templates** — parameterized built-in types or image backgrounds:

```json
{
  "id": "my-templates", "name": "My templates", "description": "…",
  "type": "template", "author": "Your name", "license": "CC-BY-4.0", "version": "1.0.0",
  "templates": [
    { "name": "Wide ruled", "params": { "type": "ruled", "spacing": 64, "lineColor": "#9DB6D9" } },
    { "name": "Weekly planner", "image": "packs/my-templates/planner.png", "infinite": false }
  ],
  "preview": "packs/my-templates/preview.png"
}
```

Supported `params.type` values are `blank`, `sheet`, `ruled`, `grid`, `dots`, `music`, `planner`, and `habit`. `params.infinite` defaults to `true` and determines whether the pattern is an infinite canvas or a fixed sheet.

**Palettes** — between 2 and 16 `#RRGGBB` colors:

```json
{ "id": "ocean-palette", "name": "Ocean", "type": "palette", "palette": ["#0EA5E9", "#0369A1"], … }
```

**Stickers** — transparent PNG images:

```json
{ "id": "stars", "name": "Stars", "type": "stickers",
  "stickers": ["packs/stars/star.png", "packs/stars/sparkle.png"], … }
```

## Rules

- Submit only **original or freely licensed content**. Accepted licenses are `CC0-1.0`, `CC-BY-4.0`, and `CC-BY-SA-4.0`.
- Do not submit trademarks, offensive content, or personal data.
- For removals, open an issue with the `takedown` label (DMCA/copyright process).
